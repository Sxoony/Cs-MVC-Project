# Health Systems Enterprise Staff Operations Platform


A Staff Management System supporting CRUD operations, using a layered architecture


## Description
Following a scenario of a project, this is tasked to develop a secure, modular and scalable web-based staff management system using C# and ASP.NET Core MVC 


## Features
- Enforcing administrator-only access
- Full CRUD functionality for managing staff
- Using in-memory storage (future database-ready)
